# Project rules

- Keep the quiz self-contained in `index.html`; avoid adding a server or build step.
- Preserve the space-exploration quiz flow, mission-control visual style, and light/dark themes.
- Keep interactions accessible: use semantic controls, visible keyboard focus, readable contrast, and reduced-motion support.
- Keep changes focused and lightweight; avoid dependencies unless they are clearly necessary.
- After changing behavior or styling, open the page in a browser and check the affected experience.
